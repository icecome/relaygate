# RelayGate 前端 ui-design-review 审查报告（v5.0 升级前基线）

> 范围：`web/src/**`（53 文件）+ `web/index.html` + `web/tailwind.config.ts`；对照参考项目：workbuddy2api-panel（Go 内嵌面板）、workbuddy2api-hub（dashboard.html）、workbuddy-manager（Next.js，源码级）。
> 方法：ui-design-review 技能审计序列（anti-slop → a11y → 字体色彩 → 布局 → 动效 → 表单 → 状态 → 语义）。

## 审计结论总览

**A11y 与工程基础是强项**（Toast aria-live、Modal 焦点陷阱、tablist 键盘惯例、focus-visible 全局 ring、tabular-nums 纪律均已到位）；**决定性短板集中在三层**：①移动端零断点（结构性缺陷）②亮色 only ③信息架构双缺陷（三层导航嵌套 + 概览与账号页表格重复）。

## 发现清单

### CRITICAL（阻断性）

- **[CRITICAL] Layout.tsx:8 + Sidebar.tsx:27 — 移动端零适配**。`flex h-screen` + 固定 `w-52` 侧栏，390px 视口下主区仅剩 ~190px，内容竖排挤压（实测截图已在对比报告留档）。表格组件 `min-w-[880px]`（AccountTable.tsx:56）在该视口下完全不可用。这是整个 v5 前端升级的第一优先。

### MAJOR

- **[MAJOR] index.css:6 `color-scheme: light` — 亮色 only**。tailwind.config 无 darkMode 配置。对常驻后台/夜间查看的运维面板是可用性缺口。panel 已示范 `[data-theme]` 双色板全量做法（panel index.html:10-42），本项目令牌（ink/line/surf/acc）结构完全兼容双色板改造。
- **[MAJOR] 信息架构：三层嵌套导航**。Sidebar（一级）+ SectionTabs（二级，SectionTabs.tsx）+ 页内 Panel 头（三级），而 SectionTabs 在窄屏会随 seg-track `overflow-x-auto` 溢出滚动。参考 panel 的七视图平铺（单层 hash 路由）更扁平；manager 用 App Router 保持层级但每层独立且少。建议：一级保留侧栏，二级 tabs 收入页面头而非全局 sticky 条。
- **[MAJOR] Overview.tsx:261-309 与 AccountTable.tsx 功能重复**。概览页内嵌了一份 6 列账号表（前 8 个），与账号页主表 80% 字段相同，两处维护成本高且口径易漂移（账号页有"状态冷却原因"，概览页没有）。参考 manager：概览只做「健康度汇总卡」不下钻明细。建议概览表格降级为「池健康摘要条」。
- **[MAJOR] AccountTable.tsx:147-187 — 操作列 6 个文字按钮平铺**（详情/刷余额/禁用/清冷却/签到/重置指纹/删除），行宽被操作列吃掉约 380px，挤压数据列；且「删除」与「详情」等高危/普通操作视觉重量相同（仅 color 区分），违反"破坏性操作不与常用操作竞争视觉"原则。参考：panel 行内只留 2 个主操作 + 「更多」菜单；manager 用 RowMenu 下拉。
- **[MAJOR] index.html — 无 theme-color meta**（对比 Guide 做法缺失）；无 `<meta name="color-scheme">`，v5 引入暗色后浏览器原生控件（scrollbar/表单）会不适配。

### MINOR

- **[MINOR] Overview.tsx:186 — 执行链时间戳 `pill-muted mono`**：`mono` 非既有类（存在 `font-mono`），疑似笔误；且时刻文案（如 "09:00"）用 pill 容器语义不符（非状态）。建议纯文本 `tabular-nums`。
- **[MINOR] StatCard.tsx:29 — clickable 卡片 hover 只有边框色变化**，无 focus-visible 样式补偿（tabIndex=0 有键盘路径但视觉焦点缺失，依赖全局 outline 兜底——可用但偏弱）。
- **[MINOR] AccountTable.tsx:30-31 空态文案**引导语提到「OAuth 登录」，但当前版本账号页没有 OAuth 入口（WB OAuth 是 v5 计划项）——文案先于功能，空态承诺了不存在的能力。
- **[MINOR] Header.tsx:17 — 顶部左侧是静态文字 "Trae · WorkBuddy 账号池网关"**，信息价值低且与 Sidebar 品牌区重复。可让位给全局搜索或环境标识（panel 的做法：brand 区副标题即可）。
- **[MINOR] 长列表无虚拟化/无 content-visibility**：账号表在 100+ 账号时一次渲染全部行。manager 用 @tanstack/react-virtual；panel 用分页。当前 16 账号无碍，v5 若支持批量导入需跟上。
- **[MINOR] index.css `.note-warn` 文字色 `#78350F`** 与 warn token 家族（`text-warn`=#B45309）不同源，属于 token 漂移（对比度无问题，但维护口径应统一）。

### NIT

- **[NIT] 空态/按钮文案使用中文省略号规范已正确**（执行中…），保持。
- **[NIT] StatCard 数值 24px 与 label 12px 层级清晰**；若 v5 引入暗色，`text-acc-hover`（#065F46）在暗底上对比度不足 4.5:1，需为暗色单独映射 `acc-2`（panel 用同思路：语义色双套独立色板）。

### PASS（保持不动）

- Toast.tsx:52-54 role=status + aria-live=polite + aria-relevant ✓
- Modal.tsx 焦点陷阱 + Escape + aria-labelledby 兜底 ✓
- SectionTabs.tsx tablist + 方向键/Home/End 键盘惯例 ✓
- index.css:22 全局 :focus-visible 2px ring ✓
- 全仓无 `transition: all`、无 `outline: none`、无 `user-scalable=no`、无 onPaste 阻断 ✓
- 表格数字列 `tabular-nums` 纪律 ✓
- 反 AI 套路：无紫蓝渐变、无卡片墙滥用（卡片数受控）、单强调色（翠绿）✓
